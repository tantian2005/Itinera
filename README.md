# 路书 Itinera

**中文** | [English](README.en.md)

把 AI 整理的旅行攻略变成可以编辑的行程地图：时间线、交通、拖动排序、分享图片。

**在线使用：<https://tantian2005.github.io/Itinera/>**

没有账号，也没有服务器。行程只保存在你自己的浏览器里，攻略不会上传。

## 怎么用

1. 在首页点「复制提示词」，把提示词和你的攻略一起发给 ChatGPT、Claude 或其他 AI。
2. 把 AI 回复的内容粘贴进来，或者上传它生成的 .json 文件，也可以直接把文件拖到页面上。
3. 生成地图后，按页面顶部的检查结果修正问题，再按需要修改、调整顺序，最后分享图片或导出 JSON。

不想自己写攻略的话，可以先点「打开示例」看看效果。

## 功能

**导入**
- 代码块以外的文字会被忽略。格式有小错误也能读取，比如注释、单引号、缺少的逗号、被截断的结尾，读取后会提示修复了什么。
- 字段名不分大小写，也认常见的别名和中文名，比如 `latitude`、`纬度`、`坐标`。坐标可以写成 `51.5089° N` 这样的度分秒。
- 有地点没写坐标时，会按名称自动查找并标为大致位置，找不到的才列为问题。
- AI 常把离开时间写成到达时间，导入时会根据前后交通里的时间段推断每一站的到达和离开时间。

**检查**
导入后在侧栏顶部列出 AI 常犯的错：
- 某一站离前后两站都很远，可能放错了地点
- 某天没有从住处出发，或者没有回到住处
- 同一段交通写了两次
- 交通写进了备注，地图上看不到

能自动修的可以一键修复。其余的点「复制修改意见给 AI」，发回给 AI 重新生成。

**地图**
- 路线画成弧线，长途和航班是虚线，路线中间有方向箭头。
- 有街道和卫星两种底图，还有我的位置、比例尺，放大后会在标记旁显示地名。
- 地图上的搜索框可以搜地点，也可以粘贴 Google 地图链接或坐标；在地图上右键（手机上长按）可以直接选点添加。

**时间线**
- 每一站显示到达和离开时间。
- 两站之间是交通段：多段交通会拆成多行，每行显示交通方式图标和时间段。
- 交通方式可以手动选。不选时先看文字里的关键词，看不出来就按速度猜。

**编辑**
- 在原来的位置直接改，没有弹窗。
- 拖动把手调整顺序，也可以把一站拖到另一天。
- 工具栏里有撤销、重做、添加地点和移动地点。

**分享**
- 「分享图片」生成一张长图，上面是地图，下面是时间线。
- 手机上可以直接用系统分享发给朋友，电脑上保存为 PNG。

**其他**
- 中英双语，跟随系统的深浅色。
- 电脑上侧栏宽度可以拖动调整；手机上地图占满屏幕，行程在可以拖动的底部面板里。

## 本地运行

这是一个纯静态网页，所有程序都在 `index.html` 里，没有构建步骤：

```bash
python -m http.server 8000
```

然后打开 <http://localhost:8000/>。地图和 Leaflet 需要联网。

也可以直接双击 `index.html` 打开。这时 OpenStreetMap 不提供瓦片，会自动改用 Esri 的街道底图。

## 部署

把仓库根目录发布到任意静态托管即可。这里用的是 GitHub Pages，从 `main` 分支的根目录发布。

## JSON 格式

```json
{
  "version": 1,
  "title": "巴黎2日",
  "dateRange": "5.1–5.2",
  "places": {
    "hotel": {"name": "Hôtel du Nord", "lat": 48.8721, "lng": 2.3426, "approx": true, "kind": "hotel", "desc": "", "facts": []},
    "louvre": {"name": "卢浮宫", "nameLocal": "Musée du Louvre", "lat": 48.8606, "lng": 2.3376, "approx": false,
               "kind": "sight", "desc": "需预约", "facts": [["开放", "09:00–18:00"]], "link": "https://www.louvre.fr"}
  },
  "days": [
    {"date": "5.2", "weekday": "周六", "title": "卢浮宫", "notes": "07:30 早饭",
     "stops": [
       {"place": "hotel", "time": "", "end": "08:30", "mode": "subway", "leg": "08:30–08:50 地铁 7 号线"},
       {"place": "louvre", "time": "09:00", "end": "12:00", "leg": ""}
     ]}
  ],
  "backups": []
}
```

| 字段 | 说明 |
|---|---|
| `kind` | `sight`、`food`、`hotel`、`transport`、`backup` |
| `approx` | 坐标是否只是大致位置 |
| `time` / `end` | 到达和离开时间 |
| `leg` | 去下一站的交通。多段交通用「；」分开，每段以时间段开头 |
| `mode` | 去下一站的主要交通方式：`walk`、`subway`、`bus`、`train`、`car`、`boat`、`flight`，可以省略 |
| `nameLocal`、`link` | 当地名称或地址、官网，可以省略 |
